Key Insights

Accuracy vs. F1-Score

On imbalanced datasets, accuracy can be misleading. A model that always predicts the majority class achieves high accuracy. F1-Score balances precision and recall, revealing true classifier performance.

ROC-AUC: Threshold Independence

ROC-AUC measures a model's discriminatory ability across all classification thresholds. It is useful for comparing classifiers, but can be optimistic on imbalanced data as it incorporates true negatives.

PR-AUC: Suited for Imbalanced Data

Precision-Recall AUC focuses solely on the positive class. For imbalanced datasets such as income prediction, PR-AUC provides a more informative evaluation than ROC-AUC.

Metric Choice Alters Rankings

Classifier rankings change depending on the chosen metric. This demonstrates why a single metric is insufficient. A comprehensive evaluation requires all four metrics examined together.
